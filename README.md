# FieldOps Auth (P2)

Frontend-only React Native app. There is **no backend** in this project.

Sign up and sign in go straight to **Firebase Authentication** (`fieldops-47bbf`):
- Email + password
- Phone number + OTP

## Run
```bash
cd P2/frontend
npx expo start --clear
```

Open in Expo Go, an emulator, or press `w` for web.

## Firebase console
Enable these providers for `fieldops-47bbf`:
1. Email/Password
2. Phone
